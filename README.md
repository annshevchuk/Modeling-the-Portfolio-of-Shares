Чтобы запустить код, cкачайте все файлы кнопкой Download ZIP по зелёной кнопке (< > Code) и обязательно разархивируйте.
Выполняя файлы последовательно от 00 до 05, Вы увидите полные файлы с результатами в появившейся папке results.

Чтобы не тратить время на скачивание данных с MOEX, Вы можете воспользоваться готовыми словарями, которые автоматически скачаны с архивом.
Для этого внутри папки с файлами проекта, создайте папку с названием data и переместите в неё файлы с названиями:
- prices_dict_2023_2024.pkl
- prices_dict_2024_2025.pkl
